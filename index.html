01 · ORIGIN

The address wasn't chosen.
It was observed.

Most coins get a random address from a laptop. $STAR's came from the sky.

Right now about ten thousand Starlink satellites are circling the planet in thin shells, 340 to 570 km up, each one tracked and published as a two-line orbital element set. Those numbers are public, they change constantly, and nobody controls all of them at once.

We committed to one exact future second. At that second we froze the entire constellation, hashed it, and let it decide the mint. Then we published everything so you can do the math yourself.

Orbital data: CelesTrak public GP elements. $STAR is a community memecoin and is not affiliated with, endorsed by, or connected to SpaceX or Starlink.

Four steps.
No trust required.

    COMMIT

  3. 03

    DERIVE

    The sky and the committed entropy go through HKDF-SHA256, which produces 32 bytes. Those bytes are the Ed25519 seed of the mint keypair, the same thing as Solana's Keypair.fromSeed.

    seed = HKDF-SHA256(
  ikm  = entropy ‖ sha256(snapshot),
  salt = "STAR-MINT-v1",
  info = "STARLINK-GP|" + snapshot_utc,
  L    = 32 )
mint = Ed25519.fromSeed(seed).publicKey

    PENDING
  4. 04

    PROVE

    Once the mint exists we reveal the entropy and publish the raw snapshot and the script. Anyone can check that the entropy matches the commitment and the snapshot matches its hash, and that the result is the CA.

    ENTROPY
    SEALED UNTIL MINT
    VERIFIED
    —

Why the secret entropy? The snapshot is public the instant it's taken. If the sky alone made the seed, anyone could compute the mint's key at the same moment we do and race us to it. The sealed entropy stops that. The committed hash proves we couldn't swap it later, and the sky proves we couldn't pick the outcome in advance.

03 · VERIFY

Recompute it yourself.

The script is short, has zero dependencies, and runs on Node 18+. It canonicalizes the snapshot, checks the hashes and derives the address, then names the satellite that "decided" it.

# 1 · get the published snapshot + script
git clone <repo> star && cd star

# 2 · recompute (no npm install needed)
node scripts/derive-star-address.mjs \
  --snapshot proof/snapshot.tle \
  --time     <SNAPSHOT_UTC> \
  --entropy  <REVEALED_ENTROPY> \
  --expect   <CA>

# → "match": true, plus the decider satellite

# also check: sha256(entropy) == commitment
echo -n <REVEALED_ENTROPY> | xxd -r -p | sha256sum

Want a dry run before launch? node scripts/derive-star-address.mjs --test runs a public test vector (entropy = 00…1f) against the bundled constellation.

05 · FAQ

Questions from the ground.

Is the globe real?

Yes. Every point is a real Starlink satellite from CelesTrak's public element set, moved forward to this second in your browser with SGP4, the standard model for these elements. The day/night line comes from the Sun's position at the current UTC time. Tap a point to see which satellite it is.

Are you SpaceX? Is this a Starlink product?

No. $STAR is an independent community memecoin. We use public orbital data that anyone can download. We aren't affiliated with, endorsed by, or connected to SpaceX or Starlink in any way, and we don't use their logos or trademarks.

Couldn't you just keep re-rolling until you liked the address?

No. The snapshot second, the rules and the entropy hash are all published before the snapshot. Each one is fixed, so there's exactly one valid answer. If the revealed values don't hash to what we committed, the proof fails in public.

Why does the satellite count change?

Satellites launch, deorbit and get re-cataloged constantly. The live globe shows the latest public set. The snapshot that decided the address is frozen forever as a file anyone can hash.

What is the "decider" satellite?

Just for fun: the derived seed also points at one satellite in the snapshot, and we highlight it on the globe after launch. It doesn't control anything. It's the satellite that happened to be on duty that second.

Does any of this make $STAR worth something?

No. The provenance proves where the address came from, and that's all. $STAR is a memecoin with no intrinsic value, no promised returns, and no roadmap obligations. Prices can go to zero.
